## INSTALLATION COMMAND
- > git clone https://github.com/aldnnnz/nextcloud-docker-compose.git
- > cd nextcloud-docker-compose
- > cp .env.example .env
- > nano .env (change-pass)
- > docker compose up -d


## Features

- Nextcloud 31
- MariaDB 11.4
- Redis caching
- Dedicated Cron container
- Persistent Docker volumes
- Environment-based configuration
- Production-ready structure
